核心功能
📋
收支记录管理
完整的交易记录 CRUD，支持多条件筛选与分页。分类标签体系含 13 类预置分类 + 自定义分类，默认分类保护 + 关联交易校验。
📊
数据可视化仪表盘
基于 pyecharts + pandas，折线图看趋势、玫瑰图看占比、柱状图看对比，支持本周/本月/本年时段联动切换。
📥
银行账单批量导入
支持 Excel / CSV 多格式解析，智能列映射 + 预览校验 + 自动分类匹配，一键批量导入历史账单。
📅
日历视图查询
月历网格直观展示每日收支，集成农历转换、节假日与节气标注，点击日期即可加载当日交易明细。
🏷️
分类管理
可视化分类管理页面，支持新增 / 编辑 / 删除操作，默认分类保护机制，关联交易校验防止误删。
项目亮点
🤖

AI 智能省钱建议

创新性接入 DeepSeek 大模型 API，对用户支出数据进行聚合分析，生成个性化消费优化方案。
🔒 隐私保护设计 — 仅发送统计摘要，不传输原始交易明细
